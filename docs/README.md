# Documentation

Planning and specification for this project is managed with
[OpenSpec](https://github.com/Fission-AI/OpenSpec).

- **Source of truth:** [`openspec/`](../openspec/)
  - `openspec/config.yaml` - project context and conventions
  - `openspec/specs/` - current system behavior (capabilities)
  - `openspec/changes/` - in-flight proposals (requirements, design, tasks)
  - `openspec/changes/archive/` - completed changes
- **Historical material:** [`planning-archive/`](./planning-archive/) -
  original Czech planning drafts (high-level context, MVP roadmap, MVP1
  implementation plan). Migrated into OpenSpec on 2026-10-26; kept only as
  historical reference, not maintained.

New MVP/feature documentation MUST be written as OpenSpec changes
(`/opsx-propose`), not in this directory.
